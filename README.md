# Zihao Zhao Academic Website

Static GitHub Pages prototype for a personal academic homepage, rebuilt in a
compact academic style inspired by Minimal Mistakes-based researcher homepages.

## Preview Locally

Open `index.html` in a browser, or run a simple local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy With GitHub Pages

1. Push this repository to GitHub.
2. In the repository settings, open **Pages**.
3. Set the source to **Deploy from a branch**.
4. Choose the `main` branch and the repository root.

## Files

- `index.html`: page content, education, experiences, and projects.
- `assets/styles.css`: visual design and responsive layout.
- `assets/script.js`: dynamic footer year.
- `assets/avatar.jpg`: profile image.
- `assets/imperial-college-london-logo.png`: Imperial College London logo used in Education.
- `assets/peking-university-logo.png`: Peking University logo used in Experiences.
- `assets/shanghai-jiao-tong-university-logo.png`: Shanghai Jiao Tong University logo used in Experiences.
